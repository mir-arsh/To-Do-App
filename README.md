# To-Do List App
A clean and lightweight task manager built with **HTML**, **CSS**, and **JavaScript**. It focuses on speed, clarity, and essential features for everyday productivity.

## Features
* **Create, edit, update, delete** tasks
* **Mark tasks complete** and **remove completed items**
* **Filters** for *All*, *Active*, and *Completed*
* **Live statistics** showing task counts
* **Local storage support** so tasks persist

## How It Works
1. Add a task using the input field.
2. Click a task to toggle completion, or double-click to edit.
3. Use filters to switch views.
4. Clear completed tasks with one action or delete manual tasks.

## Setup
Simply open `index.html` in a browser. No dependencies or build tools required.
